# Secure Vault

Ứng dụng Android quản lý mật khẩu và giấy tờ tùy thân, hoạt động ngoại tuyến, mã hóa cục bộ, có tự động điền an toàn. Yêu cầu bảo mật dựa trên OWASP MASVS, kiểm thử theo OWASP MASTG.

## Công nghệ
Kotlin, Jetpack Compose, MVVM, Room, Android Keystore, BiometricPrompt, Android Autofill Framework.
